================================================================================
TROUBLESHOOTING
================================================================================

❌ "Cannot connect to localhost\SQLEXPRESS"
   → Make sure SQL Server is running
   → Check SQL Server Configuration Manager

❌ "Database creation failed"
   → Check data folder path in 01_CreateDatabase.sql
   → Default: C:\Program Files\Microsoft SQL Server\MSSQL16.SQLEXPRESS\MSSQL\DATA\

❌ "Tables not created"
   → Ensure you switched to SvagsCorporateDb before running 02_CreateTables.sql
   → Look at top-left dropdown in SSMS query window

❌ "Seed data not inserted"
   → Run 04_VerifyDatabase.sql to check table count
   → Check for any error messages in output

❌ ".NET app can't connect to database"
   → Verify connection string in appsettings.json
   → Check database name: SvagsCorporateDb (not SvagsCorporate or other variations)
   → Run 04_VerifyDatabase.sql to confirm database exists and is accessible
